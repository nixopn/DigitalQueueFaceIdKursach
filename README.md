# Электронная очередь с распознаванием лиц

Автономный терминал (Python) + веб-мониторинг (Go). На ноутбуке камера берётся из браузера; на Luckfox — CSI SC3336 и дисплей ILI9431.

## Запуск на ноутбуке

```bash
chmod +x scripts/run.sh
./scripts/run.sh
```

Откройте http://127.0.0.1:8080

1. Разрешите доступ к камере в браузере (нужен localhost).
2. В списке устройств выберите встроенную камеру или USB.
3. Нажмите **Распознавание**. Первый раз система зарегистрирует лицо и выдаст номер; повторно — узнает его.
4. **Предзаказ** → позиции → **Распознавание** привязывает заказ к клиенту.
5. Вкладки **Монитор**, **Админ**, **Статистика** обновляются по SSE.

Киоск на `http://127.0.0.1:8080` рассчитан на тач: крупные кнопки, работает и мышью, и сенсорным экраном.

## Два способа камеры

| Режим | Когда | Как |
|---|---|---|
| **Камера браузера** (по умолчанию) | Ноутбук, проверка лица, USB-веб-камера в Chrome/Safari | `getUserMedia`, кадр уходит в `POST /api/recognize` |
| **Камера терминала** | OpenCV на ПК, USB `/dev/videoN`, CSI SC3336 на Luckfox | В админке backend `opencv` или `v4l2`, затем на киоске источник «Камера терминала» |

Переключение без перезапуска: **Админ → Камера терминала**.

## Плата Luckfox

```bash
QUEUE_CONFIG=config.luckfox.yaml python -m terminal
STATIC_DIR=web/static go run ./web
```

В `config.luckfox.yaml`:

- `camera.backend: v4l2`, `device: /dev/video0` — поток V4L2 с SC3336
- `display.backend: both` — веб-киоск + `/dev/fb0` (ILI9341), сенсор `/dev/input/event0`

Фрагменты Device Tree: `deploy/luckfox/overlay.dts`.

## Состав

- `terminal/` — захват, LBP-вектор лица, SQLite, REST/SSE
- `web/` — Go-прокси и HTML/JS
- `data/queue.db` — клиенты, очередь, заказы, события

Python API слушает `:8081`, веб-интерфейс — `:8080`.
